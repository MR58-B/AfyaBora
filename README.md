# AfyaBora Kenya — Enhanced Bootstrap 5 HIV & AIDS Awareness Website

**AfyaBora** is a mobile-responsive HIV & AIDS awareness, prevention, and care website tailored for Kenya, built with **HTML5**, **Bootstrap 5.3**, **custom CSS3**, and **vanilla JavaScript**.

## Folder Structure
- `index.html` — Full responsive website featuring an urgent 72-hour PEP alert modal, sticky Bootstrap 5 navbar, automatic 3-slide hero background carousel, comprehensive HIV/AIDS education for Kenya, interactive Window Period Estimator, Myths vs. Facts flip cards, searchable Glossary, and the **AfyaBora HIV Knowledge Quest** mini-game.
- `contact.html` — Dedicated Contact & Kenya Care Map page featuring an interactive Leaflet/OpenStreetMap map of Kenyan Comprehensive Care Centres (CCCs), county/region filtering, 24/7 toll-free helplines (`1190` / `1195`), social media links, and a validated confidential inquiry form.
- `css/style.css` — Custom healthcare color theme (`#0F766E` Teal, `#15803D` Green, `#B91C1C` Awareness Red, `#F4F9F8` Mint), glassmorphism hero overlays, and responsive utilities.
- `js/script.js` — Vanilla JavaScript powering the 10-question randomized Knowledge Quest game (with score, streak multiplier, optional countdown timer, and certificate sharing), Window Period Estimator, Myths vs. Facts reveal cards, and live Glossary search.
- `assets/images/` — Local SVG illustrations depicting Kenyan healthcare workers, community support/U=U, Kenyan balanced nutrition, HIV awareness ribbon, and hero slide fallbacks.

## How to Run
Extract the ZIP folder and open `AfyaBora/index.html` in any modern web browser.
